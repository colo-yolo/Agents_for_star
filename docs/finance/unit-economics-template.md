# 单台经济性和预算模板

版本: v0.1
Owner Agent: Finance Agent

## 成本假设

所有金额为待验证估算, 采购、供应商报价和认证费用不得在未验证前写成事实。

| 项目 | 单位 | 估算区间 | 验证来源 | Owner |
|---|---|---|---|---|
| 主控 | 每台 | 待验证 | 开发板报价 | Supply Chain Agent |
| 音频模块 | 每台 | 待验证 | 供应商或电商报价 | Supply Chain Agent |
| 视觉模块 | 每台 | 待验证 | 供应商或电商报价 | Supply Chain Agent |
| 屏幕或 LED | 每台 | 待验证 | 供应商报价 | Supply Chain Agent |
| 电源和线材 | 每台 | 待验证 | 供应商报价 | Supply Chain Agent |
| 外壳 | 每台 | 待验证 | 3D 打印或打样报价 | Hardware Architect Agent |
| 包装 | 每台 | 待验证 | 包装供应商 | Supply Chain Agent |
| 云端推理 | 每用户每月 | 待验证 | 模型和调用量评估 | AI ML Agent |
| 存储和服务 | 每用户每月 | 待验证 | 云服务估算 | Backend Agent |

## 收入模式候选

| 模式 | 描述 | 优点 | 风险 |
|---|---|---|---|
| 硬件一次性购买 | 用户购买设备 | 简单直接 | 后续模型成本缺口 |
| 硬件加订阅 | 设备收入加月费 | 覆盖云端和 Agent 成本 | 用户接受度需验证 |
| 软件优先订阅 | 先用软件模拟硬件入口 | 快速验证 | 硬件差异化弱 |
| 试点服务费 | POC 阶段按试点收费 | 现金回流快 | 服务交付压力 |

## Phase 0 预算门槛

- POC 样机数量: 1 到 3 台。
- 不做模具。
- 不做认证支出。
- 不承诺量产交期。
- 单次采购必须由创始人审批。

## 周度财务指标

| 指标 | 当前值 | 目标 | 备注 |
|---|---|---|---|
| 已花费现金 | 待填写 | 控制在 Phase 0 预算内 | 每周更新 |
| 预计 POC BOM | 待填写 | 有区间即可 | 不要求量产成本 |
| 云端单任务成本 | 待填写 | 可估算 | 需模型路由 |
| 试点意愿数量 | 待填写 | 至少 3 个 | 来自访谈 |
| 付费意愿区间 | 待填写 | 有数字信号 | 来自访谈 |
