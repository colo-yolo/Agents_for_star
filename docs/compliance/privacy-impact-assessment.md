# 隐私影响分析初稿

版本: v0.1
Owner Agent: Compliance Agent

## 结论摘要

该产品可能处理语音、图像、任务文本、客户反馈、商业计划和供应商信息。Phase 0 只能作为隐私风险识别和设计约束, 不能视为法律意见或正式合规结论。任何对外发布、客户试点和量产前必须重新审查。

## 数据类型

| 数据 | 是否敏感 | 用途 | 默认策略 |
|---|---|---|---|
| 语音片段 | 可能敏感 | 创建任务、会议摘要、指令识别 | 最小采集, 可关闭 |
| 图像或视觉事件 | 可能敏感 | 场景理解、状态记录 | 默认可选, 显式开启 |
| 任务文本 | 可能包含商业秘密 | Agent 路由和文档生成 | 存入事实源前人工可审阅 |
| 客户反馈 | 可能含个人信息 | 产品决策 | 脱敏记录 |
| 供应商信息 | 商业敏感 | BOM 和采购评估 | 限制访问 |
| 审计日志 | 内部敏感 | 追踪动作和审批 | 保留但不公开 |

## 隐私原则

- 默认最小采集。
- 物理静音优先于软件开关。
- 明确显示采集状态。
- 高风险数据进入外部模型前需要脱敏或审批。
- 对外展示材料不得包含未授权客户或供应商信息。

## 用户控制

| 控制项 | Phase 0 要求 |
|---|---|
| 物理静音 | 必须进入硬件需求 |
| 状态灯 | 必须进入硬件需求 |
| 数据删除 | POC 前定义删除流程 |
| 本地缓存 | POC 前定义保留时间 |
| 云端上传 | 默认只上传任务所需内容 |

## 高风险场景

| 场景 | 风险 | 处理 |
|---|---|---|
| 长期开启麦克风 | 用户不信任或误采集 | 物理静音和状态灯 |
| 摄像头进入办公环境 | 捕获屏幕、文件或人物 | 默认关闭或无摄像头版本 |
| 客户访谈进入模型 | 泄露客户身份或商业秘密 | 脱敏后处理 |
| Agent 自动对外回复 | 误承诺或泄露信息 | 人工审批 |

## Phase 0 待验证事项

- 目标用户是否接受桌面麦克风设备。
- 摄像头是否应从 MVP 中移除。
- 试点用户愿意提供哪些数据。
- 数据保留时间的可接受范围。
- 是否需要面向美国、欧盟或中国市场分别制定策略。
