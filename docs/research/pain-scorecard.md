# 痛点强度评分表

用途: 将用户访谈中的主观反馈转为可比较证据。不得填写未发生的访谈数据。

## 评分维度

| 分数 | 描述 | 判定标准 |
|---|---|---|
| 0 | 无痛点 | 用户没有该问题 |
| 1 | 轻微 | 偶尔发生, 不影响进度 |
| 2 | 中等 | 每周发生, 有替代方案 |
| 3 | 强烈 | 每周多次发生, 明显消耗时间 |
| 4 | 严重 | 阻碍产品、销售或交付 |
| 5 | 关键 | 用户愿意为解决方案付费或试点 |

## 主场景选择规则

- 平均分低于 3 的痛点不能作为 Phase 1 主场景。
- 没有至少 5 条访谈证据前, 只能标记为候选场景。
- 若痛点强但硬件接受度低, Phase 1 优先用软件模拟硬件入口。
