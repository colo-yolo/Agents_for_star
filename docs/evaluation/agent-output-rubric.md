# Agent 输出质量评分 Rubric

用途: 评价 Agent 输出是否可用于一人公司运营。

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 正确性 | 与任务无关 | 部分相关 | 基本正确 | 准确且引用事实源 |
| 可执行性 | 无行动 | 行动模糊 | 有步骤 | 有 Owner、路径、验收 |
| 风险识别 | 忽略风险 | 提到泛泛风险 | 识别主要风险 | 风险有等级和审批 |
| 成本意识 | 无成本意识 | 提到成本 | 有成本假设 | 成本可追踪 |
| 人工修改量 | 基本重写 | 大量修改 | 少量修改 | 可直接审阅采用 |

## 通过标准

- 内部草案平均分不低于 10。
- 高风险任务必须在风险识别维度得 3 分。
- 低于 8 分的输出进入失败案例库。
