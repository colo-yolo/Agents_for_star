# 用户访谈脚本

目标: 验证一人公司创始人是否需要“智能 AI 硬件 + 多角色 Agent 操作系统”, 以及最小可行入口应该是桌面设备、随身设备还是软件模拟硬件。

访谈对象: 独立创业者、一人公司创始人、早期硬件或 AI 产品负责人。

建议时长: 30 到 45 分钟。

## 开场

感谢你参与访谈。本次不是销售, 目标是理解你每天如何处理创业任务、AI 工具和工作流。访谈不会记录敏感商业秘密, 如有不方便回答的问题可以跳过。

## 背景问题

1. 你现在的业务或项目处于什么阶段。
2. 你每周大约花多少时间在产品、客户、代码、供应链、销售和运营上。
3. 你目前使用哪些 AI 工具。
4. 你现在的主要事实源是什么: GitHub、Notion、飞书、Obsidian、Excel、聊天记录或其他。

## 痛点问题

1. 最近两周, 哪些任务因为你一个人处理不过来而延迟。
2. 哪些信息最容易丢失: 客户反馈、产品想法、技术决策、供应商信息、财务数字或销售线索。
3. 哪些任务你重复做了很多次但价值不高。
4. 你最希望 AI 帮你推进到哪一步: 草稿、任务、代码、邮件、报价对比、复盘还是审批。

## 硬件接受度

1. 你是否愿意在桌面放一个带麦克风的 AI 工作助理。
2. 什么情况下你会接受摄像头或视觉传感器。
3. 物理静音键、状态灯、本地唤醒、默认不上传原始音视频, 哪个最重要。
4. 你更偏好桌面设备、随身设备、会议终端还是软件优先。

## Agent 工作流

1. 如果 AI 有产品经理、工程师、合规、财务和销售角色, 你最希望先启用哪个。
2. 哪些动作可以自动执行。
3. 哪些动作必须你审批。
4. 你希望每周看到怎样的经营复盘。

## 购买和试点

1. 如果产品每周节省你 5 小时, 你愿意支付多少。
2. 你更接受硬件一次性购买、订阅, 还是硬件加订阅。
3. 你是否愿意参与 4 到 6 周 POC 试点。
4. 你判断试点成功的标准是什么。

## 记录模板

| 字段 | 内容 |
|---|---|
| 访谈日期 | YYYY-MM-DD |
| 访谈对象 | 姓名或匿名编号 |
| 业务阶段 | 想法、POC、早期收入、增长、其他 |
| 最强痛点 | 一句话 |
| 当前替代方案 | 工具和流程 |
| 硬件接受度 | 高、中、低 |
| 必须审批动作 | 列表 |
| 试点意愿 | 是、否、待定 |
| 价格信号 | 数字或区间 |
| 关键原话 | 不超过 5 条 |
| 后续动作 | 具体动作 |
