# PRD v1: 智能 AI 硬件 OPC 工作助理

版本: v1
日期: 2026-06-07
Owner Agent: Product Manager Agent

## 一句话产品

一个桌面或随身 AI 工作助理硬件, 帮助一人公司创始人用语音、现场输入和审批流调度多角色 Agents, 自动推进产品、研发、供应链、合规、销售和运营任务。

## 目标用户

Phase 0 主假设用户:

- 独立创业者或一人公司创始人。
- 正在做 AI、硬件、SaaS 或内容型产品。
- 每天需要处理产品规划、客户沟通、文档、代码、供应商和运营复盘。
- 痛点不是缺少聊天机器人, 而是缺少能把工作推进到文件、任务、证据和审批的操作系统。

## 核心问题

创始人每天产生大量想法、会议记录、客户反馈和执行任务, 但这些输入分散在聊天、笔记、代码仓库和脑内。传统 AI 助手能生成回答, 但不能稳定把工作路由给角色、形成任务证据、控制风险并维护公司事实源。

## MVP 范围

MVP 必须完成:

- 通过硬件入口或模拟硬件入口创建任务。
- 将任务路由到至少 3 个角色 Agent: Product Manager Agent、AI ML Agent、Knowledge Ops Agent。
- 生成可审阅交付物, 例如 PRD 片段、风险条目、客户访谈摘要或 GitHub issue 草案。
- 将关键结论写入 GitHub 文档。
- 对高风险动作触发人工审批提示。

## 非目标

MVP 不做:

- 自研大模型训练。
- 医疗、金融、安防执法等高监管场景。
- 量产硬件承诺。
- 自动付款、自动签约、自动对外发布。
- 无提示的持续录音或摄像。

## 使用流程

1. 创始人说出或输入目标: “把今天客户反馈整理成下周产品优先级。”
2. Device Agent 捕获输入并生成任务摘要。
3. Orchestrator 判断任务类型和风险等级。
4. Product Manager Agent 归类需求。
5. Knowledge Ops Agent 将结论写入仓库事实源。
6. 创始人审批是否创建 issue、对外回复或改变路线图。

## 验收标准

| 能力 | 验收方式 |
|---|---|
| 任务创建 | 能从语音或文本输入生成结构化任务 |
| Agent 路由 | 每个任务有主 Agent、审查 Agent 和审批条件 |
| 文档落库 | 输出能写入指定 Markdown 文件 |
| 审批门禁 | 对外动作、付款、签约、隐私和合规动作必须等待创始人确认 |
| 可追踪 | 每个任务能追踪到输入、输出、责任 Agent 和证据 |

## Phase 0 用户验证问题

1. 你每天最常丢失或拖延的创业任务是什么。
2. 你现在如何记录客户反馈、产品想法和待办。
3. 哪些任务你愿意交给 AI 自动起草。
4. 哪些任务必须由你亲自审批。
5. 你是否愿意使用带麦克风或摄像头的工作助理硬件。
6. 什么隐私设计会让你放心使用。
7. 如果它每周帮你节省 5 小时, 你愿意支付多少。
8. 你更需要桌面设备、随身设备还是软件优先方案。
9. 你是否愿意参与 POC 试点。
10. 你判断这个产品有价值的第一证据是什么。

## 进入 Phase 1 的条件

- 至少 5 位目标用户认可核心痛点。
- 至少 3 位目标用户愿意看 Demo 或参与试点。
- 主场景被收敛为一个明确工作流。
- 隐私和安全初稿没有阻塞项。
- POC 可以用现成开发板和软件模拟实现。
