# 访问控制矩阵

状态: 产品设计初稿, 不是安全审计结论。

## 目的

为智能 AI 硬件 OPC 的 Agent、Orchestrator、设备模拟器和创始人审批流程定义最小权限边界。任何生产账号、真实客户数据、付款、签约、对外发送、隐私策略变更和安全例外都必须由创始人审批。

## 角色

| 角色 | 默认权限 | 禁止权限 | 审批要求 |
|---|---|---|---|
| 创始人 | 查看、编辑、批准、拒绝和归档全部内部资料 | 不适用 | 作为最终审批人保留记录 |
| Orchestrator | 路由任务、记录审计日志、阻断高风险动作 | 直接执行付款、签约、对外发送、删除事实源 | 高风险动作进入 `pending_founder_approval` |
| 低风险 Agent | 读取公开或仓库内资料、起草文档、运行低风险校验 | 访问密钥、客户敏感数据、外部发送工具 | 默认可执行, 需审计 |
| 中风险 Agent | 起草技术方案、成本估算、客户沟通草案 | 直接接入生产系统或外部账号 | 需要指定审查 Agent |
| 高风险 Agent | 只能起草审批包和风险说明 | 直接执行高风险动作 | 必须创始人审批 |
| 外部顾问 | 查看创始人授权的最小材料 | 访问全仓库、密钥、客户清单 | 逐项授权, 到期回收 |

## 资源分级

| 资源 | 级别 | 默认访问 |
|---|---|---|
| 公开产品草案 | 低 | 相关 Agent 可读写草案 |
| 用户访谈原始记录 | 中 | Product、Research、Customer Success 可读, 对外不可发 |
| 客户联系方式 | 高 | 默认不可访问, 创始人逐项授权 |
| 生产密钥和令牌 | 高 | Agent 不可访问 |
| 付款和银行信息 | 高 | Agent 不可访问 |
| 合同、NDA、报价单 | 高 | 只能起草摘要或审批包 |
| 审计日志 | 中 | Security、Backend、Knowledge Ops 可读 |

## 任务风险分级

| 风险等级 | 示例 | 默认动作 |
|---|---|---|
| 低 | 文档校验、内部草案、路径索引 | 可执行并记录 |
| 中 | 技术方案修改、成本情景、客户邮件草稿 | 需要审查 Agent |
| 高 | 付款、签约、对外发送、隐私策略、安全例外、量产承诺 | 阻断并等待创始人审批 |

## 最小权限规则

1. Agent 只能访问完成当前任务所需的事实源。
2. 工具权限按任务临时授予, 不做长期默认开放。
3. 高风险动作只允许形成审批包, 不允许自动执行。
4. 审批包必须包含目的、输入来源、风险等级、建议动作、回滚方式和审计记录路径。
5. 如果权限或风险等级不清楚, 默认按更高风险处理。
