# 威胁模型初稿

版本: v0.1
Owner Agent: Security Agent

## 保护目标

- 用户语音、图像、任务、客户资料和商业计划不被未授权访问。
- Agent 工具调用不能越权执行付款、签约、对外发送或删除事实源。
- 设备身份、云端 API 和审计日志可信。
- 创始人能看见数据采集状态和高风险动作。

## 资产清单

| 资产 | 风险 | 保护要求 |
|---|---|---|
| 音频输入 | 私密谈话被上传或误存储 | 默认最小采集, 支持物理静音 |
| 视觉输入 | 敏感环境泄露 | 默认关闭或显式开启, 状态可见 |
| 任务内容 | 商业机密泄露 | 访问控制和审计 |
| Agent 工具权限 | 越权执行高风险动作 | 权限分级和人工审批 |
| 设备密钥 | 设备被冒充 | 安全存储和轮换 |
| 审计日志 | 事后无法追责 | 不可静默删除 |

## 数据流

```text
Hardware input
  -> Local Runtime
  -> Cloud Orchestrator
  -> Role Agents
  -> Founder approval
  -> GitHub facts and operating systems
```

## 主要威胁

| ID | 威胁 | 场景 | 风险 | 缓解 |
|---|---|---|---|---|
| T-001 | 未授权音频采集 | 设备在用户不知情时上传音频 | 高 | 物理静音、状态灯、采集前提示 |
| T-002 | Agent 工具越权 | Agent 自动发送邮件或付款 | 高 | 高风险工具禁用自动执行 |
| T-003 | 敏感数据进入模型上下文 | 客户资料或合同被发送到外部模型 | 高 | 数据分类、脱敏、审批 |
| T-004 | API 密钥泄露 | 密钥写入仓库或日志 | 高 | 密钥扫描、环境变量、最小权限 |
| T-005 | 审计日志缺失 | 无法追踪谁触发动作 | 中 | 所有动作记录输入、Agent、输出和审批 |
| T-006 | 设备被冒充 | 非授权设备接入云端 | 中 | 设备身份和令牌轮换 |

## 权限分级

| 级别 | 动作 | 自动执行 |
|---|---|---|
| Low | 读取文档、生成内部草案、运行本地检查 | 是 |
| Medium | 创建 issue 草案、更新内部计划、整理客户反馈 | 可自动, 需审计 |
| High | 付款、签约、对外发送、发布内容、隐私和合规结论 | 否 |

## Phase 0 安全门禁

进入 POC 前必须确认:

- 设备有清晰采集状态。
- 高风险工具默认关闭。
- GitHub 不保存密钥。
- 审计日志字段定义完成。
- 敏感数据进入模型前有脱敏或审批策略。
