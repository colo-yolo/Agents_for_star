# ICP 和定位初稿

版本: v0.1
Owner Agent: Marketing Agent

## 初始 ICP

| 维度 | 描述 |
|---|---|
| 人群 | 一人公司创始人、独立开发者、早期 AI 或硬件创业者 |
| 阶段 | 想法到 POC, 或已有早期客户但团队极小 |
| 痛点 | 任务分散、上下文丢失、AI 输出无法进入执行闭环 |
| 预算 | 需要访谈验证 |
| 购买触发 | 每周因重复协调、文档、复盘浪费 5 小时以上 |
| 排除人群 | 大型企业采购、强监管行业、只需要普通聊天助手的人 |

## 定位假设

Agents for Star 是给一人公司的 AI 硬件工作入口。它不是另一个聊天机器人, 而是把创始人的语音、会议和想法转化为多角色 Agent 任务、审批和 GitHub 事实源的公司操作系统。

## 价值主张

- 从“回答问题”升级为“推进公司任务”。
- 从“单个 AI 助手”升级为“多角色 Agent 团队”。
- 从“聊天记录”升级为“可审计事实源”。
- 从“软件工具”升级为“可见、可控、有隐私状态的硬件入口”。

## 试点邀约文案草案

我正在验证一个给一人公司创始人的 AI 硬件工作助理。它可以把语音、会议和任务输入路由给产品、研发、合规、财务、销售等角色 Agent, 并把结果写入 GitHub 事实源。当前不是销售, 我想邀请你做 30 分钟访谈, 了解你是否真的需要这种工作流。

## 验证指标

| 指标 | Phase 0 目标 |
|---|---|
| 完成访谈 | 10 次 |
| 明确强痛点 | 至少 5 次 |
| 愿意看 Demo | 至少 3 人 |
| 愿意试点 | 至少 2 人 |
| 明确付费区间 | 至少 3 人给出数字 |
