# 硬件 Bring-up 和 EVT 前计划

## 目的

定义从开发板组合、首版 PCB 或样机到 EVT 前的 bring-up 路径。该计划不代表已经具备 EVT、DVT、PVT 或量产能力。

## 上电前检查

| 项目 | 方法 | 状态 |
|---|---|---|
| 目检 | 焊接、极性、短路、连接器方向、机械干涉 | 待验证 |
| 阻抗检查 | 关键电源轨对地阻抗 | 待验证 |
| 限流设置 | 根据电源轨预期电流设置实验室电源 | 待验证 |
| 调试工具 | 万用表、示波器、逻辑分析仪、功耗计 | 待验证 |
| 固件准备 | 最小启动固件、日志、调试口 | 待验证 |

## 分阶段 Bring-up

| 阶段 | 目标 | 通过标准 | 阻断条件 |
|---|---|---|---|
| 电源轨 | 确认电压、电流、纹波、温升 | 全部关键轨在预期范围 | 过流、异常发热、纹波异常 |
| 启动链路 | 确认时钟、复位、启动模式、调试口 | 可稳定进入调试或最小日志 | 复位抖动、无法调试 |
| 传感器 | 验证麦克风、摄像头或输入外设 | 能读取稳定数据并记录噪声/隐私边界 | 数据不稳定或隐私指示失效 |
| 连接 | 验证 Wi-Fi、BLE、USB 或串口 | 连接、重连和错误日志可复现 | 连接不稳定且无法定位 |
| 交互 | 验证按键、状态灯、屏幕 | 用户可理解状态和审批提示 | 状态误导或隐私风险 |
| 长时运行 | 验证温升、功耗、重启和日志 | 连续运行结果可记录 | 过热、死机、数据丢失 |

## EVT 前阻断项

- 高风险 FMEA 未关闭。
- 电源、热、隐私、无线或音频关键指标无测量证据。
- 无法复现 bring-up 结果。
- BOM 无关键替代料。
- 测试点或日志不足以定位现场问题。
- 需要采购、认证、供应商承诺或客户承诺但未创始人审批。
