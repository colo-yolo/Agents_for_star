# 记忆和上下文策略

用途: 规定 Agent 如何使用仓库事实源、访谈记录、任务上下文和外部信息。

## 事实源优先级

1. GitHub 仓库中的当前文档。
2. 已审批的决策记录。
3. 已脱敏的用户访谈记录。
4. 当前任务输入。
5. 需要联网验证的外部事实。

## 写入规则

- 战略、产品、技术、供应链、财务、安全和合规结论必须写入对应 `docs/` 目录。
- 未经验证的数据写为“待验证”。
- 未发生的访谈写为“未采集”。
- 需要创始人填写的信息写为“由创始人填写”。

## 上下文打包规则

每个 Agent 执行任务前应读取:

- `README.md`
- `AGENTS.md`
- 与任务相关的角色协议文件
- 与任务相关的事实源文件
- 最近一次相关决策记录

## 禁止事项

- 不把聊天记录当作长期事实源。
- 不把未验证外部数据写成事实。
- 不在公开文档中保留密钥、客户隐私或供应商敏感报价。
